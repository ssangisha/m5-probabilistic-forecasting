# Probabilistic Demand Forecasting for Retail Inventory Decisions (M5 Dataset)
# m5-probabilistic-forecasting
Capstone project, IIT Roorkee PG Certification in Data Science and AI.

This project forecasts daily demand for 720 retail products as a range of
likely values instead of a single number, then tests whether those ranges lead
to better stocking decisions under stated cost assumptions.

Status: work in progress. Full documentation will be added at the end.
